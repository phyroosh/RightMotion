How to get your YouTube API Credentials (3 Simple Steps)
1 Enable API

Open Google Cloud, create a project, and enable YouTube Data API v3 in the Library.

2 OAuth Consent

Set User Type to External, add YouTube upload scopes, and add your Google Email under Test Users.

3 Download JSON

Click Create Credentials > OAuth Client ID > Desktop App > Download JSON file.
